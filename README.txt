UPLOADQ TUTORIAL, READ ME TO LEARN HOW TO USE THIS
====================================================================================

UploadQ is a simple GUI tool for uploading Meta Quest builds using ovr-platform-util.

This was made to make uploading larger Meta Quest games easier by providing a simple way to upload APK and OBB files without needing to manually use terminal commands or other complicated methods.

How to use:

1. Open UploadQ.exe
2. Enter your own Meta App ID and App Secret
3. Select your APK file
4. Select your OBB file
5. Press "UPLOAD GAME"

Files:

* UploadQ.exe
  The main UploadQ application.

* ovr-platform-util.exe
  The Meta Quest upload utility used by UploadQ.

  This is included just in case you do not already have it.
  If you already have ovr-platform-util.exe, you can delete the included one or move your existing one into the same folder as UploadQ.exe.

Credentials:
UploadQ saves your entered App ID and App Secret locally in a file called credentials.key
This file is created automatically when you use the program and is not included with the download.

Requirements:

* Windows
* Meta developer App ID and App Secret
* APK and OBB files ready for upload

Notes:
UploadQ is a graphical interface for ovr-platform-util, making Quest build uploads easier without needing to manually use the command line.
